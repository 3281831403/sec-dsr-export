用户申请导出自己的数据，导出的包里混进了别人的记录，还有几个系统的数据根本没包含：导出范围必须严格限于该主体，必须覆盖全部登记在册的数据源，缺失的数据源要报告而不是静默跳过，导出包要带清单与摘要，禁止导出他人的数据，导出有时限，批量导出时各请求相互独立；同一请求两次导出的内容必须一致，导出条数必须等于各数据源条数之和。

## 数据约定

登记表由若干数据源描述组成。每个数据源有唯一名称，并可声明服务的主体范围与自身的记录序列。记录是带有主体字段的映射，其余字段由数据源自行解释。登记表保持原有排列，同一请求重复导出时名称、条数、摘要都必须一致。

导出包给出主体、登记源、缺失源、逐源记录、清单和整体摘要。清单逐源记录名称、条数与该源摘要，并给出全部源条数之和。缺失的数据源保留在登记源与清单中，缺失信息写入导出包。
